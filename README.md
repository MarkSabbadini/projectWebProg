## Website for the course of web programming @UNIBS 
### Developed with PHP Framework LARAVEL.

### Main features 
In addition to the basic pages that will describe the history and the proposed activities, there will be a section in which it will be possible to register for the various organized events.
Registration is reserved to registered users of the website, they can register in the Login section.
Admin users can see and manage events' registrations and can add/remove/update football teams displayed in the website.
